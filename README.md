# DSE 論點背誦練習

以 DSE Master Paragraph Bank v2（87 個 Master）為資料庫的背誦/練習工具。

## 功能

- **英文情境練習**：隨機給一個生活化情境（可按 A-J 範疇篩選），寫出英文段落，系統批改文法/串字並猜測對應哪個 Master 角度；記錄已答過的角度與較少練到的角度（可重複練習，不強制擋重複）。
- **中文邏輯鏈回憶**：只顯示 Master 標題與情境，自行默想①②③④邏輯鏈，再揭曉核對。
- **間隔重複**：英文/中文各自獨立記錄，1→3→7→14→30 天排程，首頁「今日待溫」自動列出到期項目。
- **範圍選擇**：可只練特定編號（例如手冊建議的「第一批必背 12 個」），或全部 87 個。
- **錯題本/生字本**：自動記錄常拼錯的字、常答錯或從未練過的 Master。
- **參考手冊**：附錄 A-D（首句改寫公式、文體範本、句式連接詞庫、考場拼題技巧）。

## 開發

```bash
npm install
npm run dev
```

## 批改方式

預設使用本機規則批改（字典串字檢查 + 基本文法規則 + 關鍵詞比對猜測 Master），完全不需要任何設定即可運作。

若想要更聰明的 AI 批改（更準確的文法建議、內容評分），在 Vercel 專案設定中加入環境變數：

```
ANTHROPIC_API_KEY=sk-ant-...
```

設定後 `/api/grade` 會改用 Claude 批改；沒有設定時會自動 fallback 回本機規則批改，不影響使用。
